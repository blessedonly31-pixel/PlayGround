# PlayGround

## Quiet Zone — The Hollow Signal

A self-contained, browser-playable first-person survival game. Choose from nine atmospheric theaters, four operations, and three weapon kits. Pulse **Resonance (Q)** to expose infected and hidden relic caches; sprinting and shooting make noise, so timing your signal is part of the challenge. The game runs locally with no account or network service.

### Controls

- **Desktop:** WASD to move, mouse to look, click to fire, **R** to reload, **Q** to pulse, **Shift** to sprint, **Esc** to pause.
- **Touch:** left virtual stick to move, drag the view to look, on-screen **FIRE** and **Q** buttons.
- Choose **Ambience: Off/On** from the field archive for an optional synthesized drone.

Serve this folder over HTTP to play and enable its offline PWA cache (for example, `python3 -m http.server 3002`). It is a web prototype, not a signed Android package; Google Play publication still requires Android packaging, store assets, testing, and a developer account.
